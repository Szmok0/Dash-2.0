# WORKFLOW.md

## Start dnia
PIN -> Dashboard -> zadania / aktywni / dzisiejsze spotkania / bez kontaktu / wymagają uwagi -> kliknięcie prowadzi do klienta.

## Wykonanie zadania
Klik zadania -> karta klienta -> właściwy wpis -> wykonanie działania -> opcjonalnie kontakt/notatka/kolejne zadanie -> status Zakończone -> powrót. Na Dashboardzie przekreślone do końca dnia.

## Telefon
Karta klienta -> + Dodaj -> Kontakt -> Telefon -> data/godzina domyślnie teraz -> status -> notatka -> Zapisz. Notatka kontaktu pojawia się również w Notatkach. Kolejne działanie tworzy się jako osobne zadanie.

## Spotkanie
+ Dodaj -> Kontakt -> Spotkanie -> data/godzina -> status -> notatka. Przyszłe spotkanie pojawia się w Kalendarzu.

## Szkolenie
+ Dodaj -> Szkolenie -> nazwa -> data -> rodzaj -> status -> notatka. Po zapisie widoczne na karcie, w Kalendarzu i Analityce.

## Notatka własna
+ Dodaj -> Notatka -> treść -> Zapisz. Nowa notatka trafia na górę.

## Wymaga uwagi
Flaga na karcie klienta + opcjonalna krótka notatka -> klient pojawia się na Dashboardzie -> po odznaczeniu znika.

## Bez kontaktu
Lista automatyczna, próg domyślny 30 dni, klik nazwiska otwiera kartę.

## Wyszukiwanie
Dashboard/Klienci: ID, imię, nazwisko. Analityka: pełne filtry.

## Import XLSX
Wybór pliku -> odczyt nagłówków -> identyfikacja po external_id -> podgląd nowych/aktualizowanych/bez zmian/błędów/duplikatów -> zatwierdzenie -> jedna transakcja -> dane robocze bez zmian.

## Ręczne dodanie klienta
Klienci -> Dodaj klienta -> stały formularz identyczny jak import -> external_id obowiązkowy i unikalny -> karta klienta.

## Zamknięcie klienta
Status Zamknięty -> znika z bieżącego Dashboardu -> pozostaje w bazie, wyszukiwaniu i raportach.
