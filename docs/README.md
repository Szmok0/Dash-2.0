# Client Workbench — pakiet startowy do kodowania

Skrócona dokumentacja implementacyjna MVP. Ma pozwolić rozpocząć kodowanie bez ponownego projektowania funkcji.

## Użycie
1. Rozpakuj pakiet do nowego repozytorium.
2. Otwórz repozytorium w Codex lub Claude Code.
3. Wklej zawartość `CODEX_PROMPT.md`.
4. Zleć wyłącznie Sprint 0.
5. Po uruchomieniu makiety oceń układ, dopiero potem przejdź do kolejnych sprintów.

Dokumenty:
- PRODUCT.md
- UI.md
- DATABASE.md
- WORKFLOW.md
- BUILD.md
- CODEX_PROMPT.md
- schema.sql
